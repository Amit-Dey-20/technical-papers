# Object- Oriented Programming

Object-Oriented Programming helps us organize Python programs using classes and objects.

---

# Important OOP Concepts Summary


- Class :- Blueprint for creating objects
- Object :- Instance of a class
- Attribute :- Data belonging to an object or class
- Method :- Function defined inside a class
- self keyword :- Represents the current object
- Constructor :- Initializes an object
- Encapsulation :- Bundles data and behavior together
- Inheritance :- Reuses functionality from another class 
- Polymorphism :- Same interface with different behavior
- Abstraction :- Hides unnecessary implementation details
- Composition :- One object contains another object
- Association :- Relationship between independent objects
- Aggregation :- Weak relationship between objects
- super() method :- Accesses parent class functionality
- Getter :- Retrieves an attribute value
- Setter :- Modifies an attribute value
- Class Method :- Method that works with the class
- Static Method :- Method independent of object/class state
- Property :- Method accessed like an attribute
- Magic Method :- Special method with `__`
- Operator Overloading :- Gives operators custom behavior
- Dataclass :- Simplifies data-focused classes
